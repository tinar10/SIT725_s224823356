
## Task 3.2P – Bootstrapping Express App

This task demonstrates building an Express web application
using **Node.js**, **Express.js**, **Materialize CSS**, and
**JavaScript**.

The application uses a **Recipe Collection** scenario to
display recipes using Materialize components.

### 3.2P Tasks

- Create an Express web application.
- Serve HTML, CSS, JavaScript, and images from a `public` folder.
- Integrate Materialize CSS components.
- Display recipes using Materialize cards.
- Implement a modal component.
- Use JavaScript for user interactions.
- Test the application using a browser.

---

### Application Features

| Feature | Description |
| --- | --- |
| Recipe Collection | Displays recipes with images and descriptions |
| Materialize Cards | Organizes recipes into cards |
| Modal | Displays additional information |
| JavaScript | Handles user interactions |
| Responsive Design | Adjusts layout for different screen sizes |
